# Changelog

## 3.0.0 (unreleased)

Redesign. See [docs/MIGRATION.md](docs/MIGRATION.md).

- New flow: `scan` → `design` → `explain` → `build` → `check` (and `remove`). Decisions live in `.harness/spec.json` with a [JSON Schema](schema/spec.schema.json).
- A rule engine derives modules from the spec and explains every module it includes or leaves out, with its cost.
- Output per tool: `AGENTS.md` block, `CLAUDE.md` importing `AGENTS.md`, skills in `.agents/skills` and/or `.claude/skills` depending on the selected tools.
- Managed blocks preserve user content and line endings; `.harness/lock.json` permits replacing only bytes the kit wrote; hand edits stop the build; `--dry-run` shows unified diffs.
- `check` separates harness consistency from running project commands (`--run`), validates scripts, imports, references and skill frontmatter, and reports always-loaded size against a configurable budget.
- `design --agent` and `design --questions --json` let an AI agent run the design conversation over the same engine.
- Examples and README embeds are generated by the CLI and verified by tests.
- Removed: v2 skills, testing profiles and context policies, `--blueprint`, `audit` token-savings estimates, `autotrigger`, Cursor `.mdc` rule, copied verifier script.
